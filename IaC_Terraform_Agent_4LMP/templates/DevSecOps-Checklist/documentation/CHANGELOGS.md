# Changelogs

The `CHANGELOG.md` file is one of the popular repository markdown files. It systematically records all notable changes made to a project, from new features and fixes to updates and deprecated elements.

Teams often skip this file due to how laborious it is to maintain manually, especially in projects with frequent integrations. However, teams that follow [commit style standards](/docs/conventions/COMMIT_CONVENTION.md) and [semantic versioning](/docs/conventions/VERSIONING_CONVENTION.md) can easily automate the process of updating the changelog file. 

**How to implement**

[Here](https://about.gitlab.com/blog/2023/11/01/tutorial-automated-release-and-release-notes-with-gitlab/) is a tutorial on how to use Gitlab to automate Release Notes and the `CHANGELOG.md` file.
