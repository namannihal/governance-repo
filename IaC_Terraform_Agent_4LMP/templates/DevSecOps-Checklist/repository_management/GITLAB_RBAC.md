# Setting Group and Project Permissions with RBAC
GitLab allows you to set user roles at both the project and group levels. These roles define what users can do within repositories, including access to environments. 

Using these permissions in conjuction with carefully designing your project/repository structure allows for a great deal of control over your deployments and deployment processes.

Correctly configuring and assigning these permissions is vital to the security & protection of your codebase and environments.

[View a full list of roles here.](https://docs.gitlab.com/ee/user/permissions.html)
