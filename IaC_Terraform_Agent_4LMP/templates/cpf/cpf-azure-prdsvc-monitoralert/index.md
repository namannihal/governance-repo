# Azure Monitor Alerts Module


## Overview

This Terraform module provisions Azure Monitor Alerts, including Activity Log Alerts, Metric Alerts, and Scheduled Query Rules Alerts. These alert types enable proactive monitoring and automated responses for Azure resources.

Based on the variables provided it will create alerts. Modules should be called multiple times to create multiple alerts.

## Key Features

- **Activity Log Alerts**: Triggered by specific Azure activity log events (e.g., administrative actions, resource changes).
- **Metric Alerts**: Triggered by metric thresholds (e.g., CPU usage, memory, custom metrics).
- **Scheduled Query Rules Alerts**: Triggered by queries against Azure Log Analytics workspaces (e.g., custom KQL queries).

### Supported Alert Actions

- **Action Groups**: Integrate with notification channels (email, SMS, webhook, ITSM, Event Hub, Automation Runbook, Logic App, Azure Function, RBAC roles).

## Prerequisites

- An existing Azure Resource Group.
- Required permissions to create monitoring resources and action groups.

## Usage

- Define the module in your Terraform configuration.
- Provide configuration for each alert type you want to enable.
- Reference the output alert IDs and names for integration with other resources.

## Security Controls

- Alerts can be configured to notify specific teams or trigger automated remediation.
- Tagging and telemetry are supported for governance and auditing.
