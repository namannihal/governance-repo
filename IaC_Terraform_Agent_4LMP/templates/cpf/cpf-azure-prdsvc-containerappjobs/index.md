# Container App Jobs module


## Overview

This terraform module creates a Container App Jobs and associated resources.

## Prerequisites

A `container app environment` needs to be deployed first.
An `Azure container registry` should be available with required images.
A `Key vault` needs to be deployed first.
A `User assigned identity` needs to be deployed first.

## Guidance

#### Usage

- This module deploys Azure Container App Jobs, which are container-based workloads designed to run to completion rather than serving continuous requests like regular Container Apps.
- Container App Jobs can be configured with three trigger types:
  - **Manual Trigger**: Jobs are executed on-demand through manual intervention or API calls.
  - **Event Trigger**: Jobs run in response to specific events like queue messages or webhook calls.
  - **Schedule Trigger**: Jobs execute on a time-based schedule defined by a cron expression.
- Each job execution runs one or more container instances, with configurable parallelism to control how many replicas can run simultaneously.
- Container App Jobs share the same Container App Environment infrastructure as regular Container Apps, benefiting from the same networking capabilities and security features.
- Container App Jobs support managed identities for secure access to Azure resources without storing credentials in your code or configuration.
