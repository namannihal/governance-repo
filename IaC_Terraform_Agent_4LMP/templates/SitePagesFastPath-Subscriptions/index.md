# FastPath Subscriptions.

## Introduction

FastPath is a feature that enables customers to optimise the performance and reliability of their network connectivity to Azure. FastPath allows customers to bypass the ExpressRoute Virtual Network Gateway and directly connect to the Azure MS Edge Enterprise (MSEE) routers and backbone network, reducing latency and increasing bandwidth and performance to their virtual networks and VMs. FastPath is available for ExpressRoute circuits with Standard, Premium, or Local SKU, and supports both private and Microsoft peering.
